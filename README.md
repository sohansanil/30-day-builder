## 🎯 What Is This?

This is not a "30 projects in 30 days" challenge.

This is a **learning journey** where projects are vehicles for understanding how modern software products are built, improved, deployed, and maintained.

Each day focuses on a specific **learning objective** — sometimes that means building something new, sometimes it means refactoring, deploying, learning a concept, or improving previous work.

## 👤 About Me

I'm a 3rd-year Data Science & Engineering student preparing for placement season. This journey documents my transformation from a student familiar with Python and data science into a builder who can design, develop, and ship real software products.
