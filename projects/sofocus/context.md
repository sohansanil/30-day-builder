# SoFocus Context

## Project

SoFocus = SOhan + Focus

Chrome Extension (Manifest V3)

Tagline:

Turn watch time into knowledge.

## Core Idea

SoFocus is NOT a distraction blocker.

We are NOT competing with Unhook.

SoFocus is a Knowledge Capture Companion.

The purpose is helping users capture insights from YouTube tutorials without leaving the player.

## MVP

### Core Flow

Watch tutorial
↓
Aha moment
↓
Press hotkey
↓
Video pauses
↓
Capture insight
↓
Save
↓
Video resumes
↓
Knowledge Vault grows

## Features

### Implemented

- Manifest V3
- Vanilla JS
- Shadow DOM overlay
- Hotkey capture
- Auto pause / resume
- Insight capture
- Local storage
- Knowledge Vault popup
- Markdown export
- Video thumbnails

## Important Product Decisions

Use the term:

- Insight
- Capture

Avoid:

- Note
- Notepad

The product is a Knowledge Capture Companion, not a note-taking app.
