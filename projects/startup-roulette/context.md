# Day 12: Startup Roulette 🎰

## The Concept
**Startup Roulette** is an addictive, single-page "dopamine slot machine" designed as a fun, creative palate cleanser after the intense AI engineering of Forge.

It generates absurd, funny, and sometimes brilliant startup ideas by spinning three randomized reels:
- **Reel 1: Product Type** (e.g., Uber, Netflix, Discord, Airbnb, Duolingo, LinkedIn)
- **Reel 2: Audience** (e.g., Gamers, Students, Parents, Pets, Developers, Grandparents)
- **Reel 3: Twist** (e.g., AI Agents, Blockchain, Voice Control, AR, Gamification, Anonymous)

Example spin: `LinkedIn` + `for College Clubs` + `using AI Agents`

## The Addictive Loop
1. The user hits a giant, tactile **[SPIN]** button.
2. The UI goes crazy with casino-style slot machine animations and sound effects.
3. The absurd idea is presented.
4. The user has two options:
   - ❌ **PASS**: Instantly spins the wheels again.
   - 🔨 **BUILD IT**: Grabs the generated idea and links the user directly into the **Forge AI Architect** (Day 11) to generate a full Product Blueprint for it.

## The Goal
This project is an **ecosystem flex**. It connects two separate projects (Startup Roulette -> Forge) in a seamless workflow, proving to recruiters that the 30-Day Builder projects are an interconnected builder universe, not just isolated apps.

## Tech Stack & Vibe
- **Frontend**: Next.js (App Router), React, Tailwind CSS
- **Animations**: Framer Motion (Crucial for the slot machine reel spin effect)
- **Vibe**: Bright, tactile, casino-esque, fun, snappy. Big buttons, confetti, satisfying clicks.
- **Logic**: Arrays, randomization, URL parameter passing (`forge-sohansanil.vercel.app?idea=...`)

## The Secret Sauce
The generated ideas shouldn't *all* be jokes. The goal is an 80/20 mix:
- 80% Ridiculous (e.g., Tinder for Pets using Voice Control)
- 20% Surprisingly Good (e.g., Duolingo for Developers using Gamification)

The funniest reaction is: *"Haha that's stupid... wait... actually..."*
