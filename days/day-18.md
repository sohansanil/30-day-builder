# Day 18

Project: SMEPay Invoice Generator

Goal: Build a professional, production-grade B2B utility tool for generating invoices.

What I Built:
A complete invoice generator for SMEPay that allows businesses to easily create, format, and download professional PDF invoices directly from the browser. Since this is an internal company product, it required high attention to brand guidelines, robust form validation, and reliable PDF generation.

Challenges:
- Ensuring the PDF output perfectly matched the web preview.
- Handling complex state for line items, taxes, and dynamic totals.
- Meeting strict corporate branding and layout requirements.

Key Learnings:
- Advanced React state management for dynamic forms.
- Client-side PDF generation techniques.
- Building tools optimized for B2B user experiences.

Tech Stack:
- React
- Tailwind CSS
- PDF Generation Libraries
