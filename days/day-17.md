# Day 17

Project:
CipherLab OS

Goal:
Build a retro 8-bit workstation for cryptography and security education.

What I Built:
A fully functional simulated 90s operating system complete with draggable windows, an interactive desktop, and three core security modules. Users can encrypt messages using algorithms like Caesar and Playfair, simulate brute-force password attacks, and hide secret messages in images using steganography.

Challenges:
Recreating an authentic retro desktop experience with functional window management (drag, minimize, focus) within React without relying on heavy external libraries.

Key Learnings:
- React state management for a multi-window UI architecture.
- Implementation of classic cryptographic algorithms (Caesar, Vigenère, Playfair, Hill).
- Handling pixel data manipulation for steganography.

Tech Stack:
Next.js, React, TypeScript, Tailwind CSS
